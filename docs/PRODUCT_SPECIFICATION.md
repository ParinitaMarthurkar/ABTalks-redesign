# ABTalks Redesign – Product Specification

## Product Vision
Build a mobile-first experience that helps students consistently complete the 60-day coding challenge with minimal friction. The focus is on clarity, motivation, and helping students build a public portfolio through GitHub and LinkedIn.

## UX Principles
- Mobile-first (390px)
- One primary action per screen
- One visually dominant CTA
- Minimal cognitive load
- Consistent reusable components
- Positive reinforcement
- Accessible touch targets and typography

## Information Architecture

### Landing (/)
- Hero
- How ABTalks Works
- Why Students Choose ABTalks
- Challenge Preview
- Final CTA

### Dashboard (/dashboard)
- Greeting
- Motivation
- Today's Challenge
- Progress
- Leaderboard Position
- Upcoming Milestone
- Achievements
- Recent Submissions

### Challenge Day (/day/12)
- Header
- Time & Difficulty
- Challenge
- Requirements
- Skills You'll Practice
- Resources
- Submission Checklist
- Submission Form
- Today's Progress
- Submit CTA

## Primary CTAs
- Landing → Start Challenge
- Dashboard → Continue Today's Challenge
- Challenge Day → Submit Today's Work

## Standout Feature
A redesigned daily completion flow including:
- Estimated Time
- Difficulty Badge
- Submission Checklist
- Completion Summary

## Edge States
- First Day
- Missed Day
- Empty Profile
- No Achievements
- No Submissions
- Challenge Completed
